Built for the person who is the only one watching.

The app describes itself
A dokkit.toml in the app's own repo says what it is and how to tell it is healthy. Nothing is wired in by hand on the server.
Nothing privileged listens
The program on each machine opens no port. Work reaches it over a connection it makes itself, and only tasks you accepted can run.
Scanning is offered, never required
Let it look over a machine and propose what to watch, or list things yourself. Nobody is asked to turn off antivirus.
On your hardware
A Windows service or a Docker container, on Postgres. Logs stay a year live, then go to your own archive.
One list, not six tools
Checks, scheduled jobs, logs, errors, versions and deploys feed the same short list. An issue closes by itself when the thing recovers.

Yours to run.

One server. Then one small program on each machine you want watched.

The server, one of these

  1. A fresh Debian or Ubuntu VPS, with a domain pointed at it
    curl -fsSL https://dokkit.dev/install.sh | sudo sh -s -- your.domain.com
  2. The same, from a checkout of the source
    sudo sh server/install.sh your.domain.com
  3. Windows, as a service, from an administrator PowerShell
    irm https://dokkit.dev/install.ps1 | iex

Then

  1. On each machine you want watched
    dokkit enrol https://your.domain.com <token>
  2. In each app's own repo
    dokkit init

What the server needs

MinimumRecommended

Estimates for about ten machines and sixty services. They have not been measured yet. The program on each watched machine needs next to nothing.
