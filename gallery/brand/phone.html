Phone

See what needs you, and whether the hardware is up, from your phone, even though your server is not on the internet. The apps are read-only, for iPhone and Android.

How it reaches you

Your server seals a snapshot, every minute.A relay holds it, and cannot open it.Your phone opens it. Nothing goes back.
Your serveron your network
A relayon any public hostcannot read it
Try the app Tap through it, on Android, iPhone or the Duo.
  • The server only ever dials out, to the relay. It opens no port for the phone.
  • Each phone has its own key and its own copy. The relay sees sealed bytes and the time they arrived.
  • The apps change nothing on the server and send no notifications. Alerts still come the ways you set on the Alerts page.

Pick a relay

The easy way: in Dokkit, open Settings, Phones and choose Use the shared relay. Dokkit makes a mailbox at relay.dokkit.dev and fills in the rest.

The shared relay holds sealed snapshots it cannot read, like any relay. A mailbox that gets no upload for 30 days is removed; press the button again for a new one.

Or run a relay of your own 3 steps

The relay is a mode of the same dokkit program, on any host your phone and your server can both reach.

  1. On that host, make a mailbox for your server. It prints the mailbox address and its upload key, once:
    dokkit relay add home
  2. Serve it behind the https proxy you already run there:
    dokkit relay serve --http 127.0.0.1:8080
  3. In Dokkit, open Settings, Phones and paste the mailbox address and the upload key.

Get the app

Install it like any other app: TestFlight on iPhone, a signed file on Android. Building it yourself is still there if you would rather.

iPhone TestFlight, iOS 17 or later
  1. On the iPhone, open the Dokkit TestFlight link.
  2. Install TestFlight from the App Store if it asks, then tap Accept and Install.

No developer account needed. TestFlight offers each new release as an update.

Android Android 8 or later
  1. On the phone, download dokkit-android.apk from the latest release.
  2. Open it and allow installs from your browser when Android asks.

It is signed with the Dokkit key, so later releases install over it as updates.

Build it yourself sign with your own account or key

Each release also carries dokkit-ios-unsigned.ipa and dokkit-android-unsigned.apk, and the source is in apps/.

iPhone, on a Mac with Xcode 16:

  1. Install XcodeGen with brew install xcodegen, then run xcodegen generate in apps/ios.
  2. Open Dokkit.xcodeproj. Under Signing & Capabilities choose your Team and a bundle identifier of your own.
  3. Turn on Developer Mode on the iPhone, connect it, and press Run.

Signed with a free Apple ID it stops opening after seven days; run it from Xcode again to renew. A paid account lasts a year. The layout for a foldable iPhone needs Xcode 27.1; an older Xcode builds the app without it.

Android:

  1. Take dokkit-android-unsigned.apk from a release, or build it with ./build-unsigned.sh in apps/android.
  2. Make a key once with keytool, then sign with apksigner sign --ks dokkit.jks.
  3. Install it with adb install, or copy it to the phone and open it.

Keep the key: an update must be signed with the same one. A copy you sign yourself cannot update the Dokkit-signed one, or the other way round.

Pair it

  1. In Dokkit, open Settings, Phones, Add a phone. A code is shown once, for two minutes.
  2. In the app, choose Servers, Add a server, and point the camera at it. Or paste the code.

One phone can follow several servers. Remove a server in the app and its key, token and saved snapshot are deleted from the phone.
