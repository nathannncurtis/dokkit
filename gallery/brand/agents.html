Connect it to your server

        
Make a token in Settings, then give it to the agent. The MCP address is your server's address with /mcp on the end.

        
    
          
  1. For Claude Code, one line:
    claude mcp add --transport http dokkit https://your.domain.com/mcp --header "Authorization: Bearer dku_..."
    2. 
          
  2. For any other MCP client, this in its settings:
    {
  "mcpServers": {
    "dokkit": {
      "type": "http",
      "url": "https://your.domain.com/mcp",
      "headers": { "Authorization": "Bearer dku_..." }
    }
  }
}
    3. 
          
  3. For a script, the same token on the API:
    curl -H "Authorization: Bearer dku_..." https://your.domain.com/api/v1/inbox
    4.
