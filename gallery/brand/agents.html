Wire an app in

Hand any coding agent this one prompt in the app's repository. It reads one file about Dokkit, describes the app, adds the library and proves it, before any server exists.

Connect it to your server

        
Make a token in Settings, then give it to the agent. The MCP address is your server's address with /mcp on the end.

        
    
          
  1. For Claude Code, one line:
    claude mcp add --transport http dokkit https://your.domain.com/mcp --header "Authorization: Bearer dku_..."
    2. 
          
  2. For any other MCP client, this in its settings:
    {
  "mcpServers": {
    "dokkit": {
      "type": "http",
      "url": "https://your.domain.com/mcp",
      "headers": { "Authorization": "Bearer dku_..." }
    }
  }
}
    3. 
          
  3. For a script, the same token on the API:
    curl -H "Authorization: Bearer dku_..." https://your.domain.com/api/v1/inbox
    4. 
        

        
dokkit.dev's own MCP, with no account before you install
Any agent can use it before a server exists. It checks a dokkit.toml, gives a starting file for a kind of service, lists the library calls for a language, and explains an error from dokkit check.
claude mcp add --transport http dokkit-help https://mcp.dokkit.dev/
