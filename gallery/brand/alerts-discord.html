Dokkit/Alerts & phone/Alerts/Discord

Discord

A message in a Discord channel when an issue opens, and another when it closes. The message can never mention anyone, whatever the issue's text says.

  1. 1Set it up
  2. 2What arrives
  3. 3Try it

Set it up

On Dokkit's Alerts page, in Settings. Only the owner can change it.

DiscordIn the channel's settings, open Integrations, then Webhooks, make a new webhook and copy its address. It starts https://discord.com/api/webhooks/.
Webhook addressOn Dokkit's Alerts page, under Webhook, paste that address and press Save.
Who is toldTick Webhook for the states the channel should hear about.

What arrives

Opened: nightly-purge did not run (db-01, DOK-12)nowIt was due at 01:00 and no start was reported. Open Dokkit

The sample company's issue, as it would arrive.

Try it

Under Discord, press Send a test. It says at once whether it went, or why not.

  • Dokkit has one webhook address, so a Discord channel takes the place of any other webhook.
  • The message says the issue, the machine and its number, the note when it opens, and a link to Dokkit.
