None of them is on a package registry yet. Each one installs from a clone of the repository, the way its own README says.

What they all do

  • With no address or key, every call does nothing. Each one reads DOKKIT_URL and DOKKIT_KEY.
  • None of them raises an error into your app. If the server cannot be reached, the app carries on.
  • An error report carries the error's type and stack, never its message.
  • A version sends one deploy line, and the server records a deploy only when the version changes.
  • A line over 64 KB is cut, and its message ends in [cut].

A machine with the dokkit program on it can report a job with dokkit run instead, which also keeps the last lines of its output.
