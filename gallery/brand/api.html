The API.

One HTTP API under /api/v1. The interface, the dokkit program, the libraries and the MCP endpoint are all clients of it, so nothing can be seen or done in the interface that the API cannot do. The same document is openapi.json, in OpenAPI 3.1.

Keys

Every call carries a key as Authorization: Bearer <key>. The prefix says what kind it is, and the server keeps only a hash.

KeyHeld byCan do
dke_ enrolment tokenPasted once into dokkit enrolOne use. Trades for a machine key.
dkm_ machine keyThe dokkit programReport for that machine, propose, take work.
dka_ app keyA library or a script inside an appWrite only, for one service. It cannot read anything.
dku_ user tokenScripts and AI toolsWhat its scopes allow: read, read-logs, act, admin.
