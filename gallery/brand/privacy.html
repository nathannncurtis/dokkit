Privacy

Dokkit is software you run yourself. These pages cover the few things dokkit.dev runs for everyone: the site, names, the shared relay and the public MCP.

The software

Dokkit runs on your own hardware. What it collects stays on your server, and nothing in the program, the server or the libraries reports to dokkit.dev.

This site

  • dokkit.dev is a static site served by GitHub Pages. It sets no cookies, runs no analytics and has no forms that send anything.
  • Its pages load fonts from Google Fonts and scripts from cdnjs and unpkg, so those services see your address when a page loads, as GitHub does for the page itself.
  • The Check a file and Move over pages work entirely in your browser. What you type or drop there is not sent anywhere.

Names

To give you a name such as yours.dokkit.dev, names.dokkit.dev keeps:

  • The account you signed in with: the provider (GitHub, Google, Microsoft or ChatGPT), the stable id it gives for you, and the display name it sends. Your email address is not asked for and not kept.
  • Each name you claim, when you claimed it, the public key your server registered, the addresses your server set for it, and when it last checked in.
  • A sign-in cookie, only while you are signed in, to keep you signed in and to stop forged requests.

A name's records are public DNS, so anyone can look up the address it points to. Released or lapsed names are deleted, with their records. Your address is held in memory for a few minutes to limit how often one connection can make requests, and is not written down.

Relay and MCP

  • The shared relay at relay.dokkit.dev keeps a mailbox for each server that signs up: sealed snapshots it cannot read, and the time each arrived. A mailbox with no upload for 30 days is deleted with its contents.
  • The public MCP at mcp.dokkit.dev reads what an agent sends it, answers, and keeps nothing.
  • Both hold your address in memory for a short while to limit requests, and do not write it down.

Ask or remove

To see what names.dokkit.dev holds for you, sign in there. To have anything removed, release your names there, or write to abuse@dokkit.dev. The source of every service is public, so you can check all of this.
