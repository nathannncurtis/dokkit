Dokkit/Alerts & phone/Desktop app

Desktop app

Dokkit for Windows, macOS and Linux: your server's own pages in a window, plus a tray icon, notifications and start at login.

  1. 1What it adds
  2. 2Get it
  3. 3Add a server
  4. 4Build it yourself

What it adds

The window is the server's own web interface, so everything the site does works there. The app adds what a browser tab cannot.

  • A tray or menu-bar icon, coloured by the worst state across your servers: green when all is fine, red when something needs you, grey when a server cannot be reached.
  • A notification for each new thing that needs you. Clicking it opens that issue.
  • It starts at login, and closing a window leaves it running in the tray.
  • Several servers, one window each, with its size and position remembered.
  • A server with a self-signed certificate can be pinned when you add it. The app shows the fingerprint and from then on accepts only that certificate.

Get it

Pick the file for your system from the latest release.

Windows signed installer
  1. Download dokkit-desktop-windows-x64-setup.exe and run it.
  2. Or, for managed installs, use dokkit-desktop-windows-x64.msi.
macOS Apple silicon and Intel
  1. Download dokkit-desktop-macos-universal.dmg.
  2. Open it and drag Dokkit to Applications.

It is signed and notarized. The app lives in the menu bar and has no Dock icon until a window is open.

Linux deb, rpm or AppImage
  1. Debian and Ubuntu: dokkit-desktop-linux-amd64.deb.
  2. Fedora and others: dokkit-desktop-linux-x86_64.rpm.
  3. Anywhere else: dokkit-desktop-linux-amd64.AppImage.

Tokens are kept in the Secret Service, such as GNOME Keyring or KeePassXC. GNOME needs an AppIndicator extension to show the tray icon, and the tray menu holds everything because AppIndicator ignores left-click.

Add a server

  1. On the server, open Settings, find Access for scripts and AI tools, tick Read and choose Make a user token. It starts with dku_ and is shown once.
  2. In the app's Settings window, enter the server's address, paste the token and choose Add server.

The token is kept in the operating system's keychain. Addresses must be https; plain http is accepted only for localhost and local network addresses, and only when you tick the box.

Build it yourself

From source Rust and the Tauri CLI
  1. Install Rust, then the Tauri CLI:
    cargo install tauri-cli --version "^2" --locked
  2. In apps/desktop/src-tauri, build:
    cargo tauri build
  3. The installers land in src-tauri/target/release/bundle/.

Windows needs WebView2. macOS needs the Xcode command line tools. Linux needs these packages:

libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libsecret-1-dev libdbus-1-dev

On Linux the build makes a .deb, an .rpm and an AppImage.
