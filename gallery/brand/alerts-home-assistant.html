Home Assistant

Home Assistant takes Dokkit's webhook as an automation trigger, so an issue can flash a light or speak on a speaker.

  1. 1Set it up
  2. 2What it sends
  3. 3Try it

Set it up

On Dokkit's Alerts page, in Settings. Only the owner can change it.

An https addressDokkit sends only to https, so Home Assistant needs an https address: its own certificate, or Home Assistant Cloud.
The automationAdd the automation below in Home Assistant, with a webhook id nobody would guess.
Webhook addressOn Dokkit's Alerts page, under Webhook, paste https://your-home-assistant/api/webhook/ and that id.

What it sends

triggers:
  - trigger: webhook
    webhook_id: dokkit-change-this-id
    allowed_methods: [POST]
    local_only: true
conditions:
  - condition: template
    value_template: "{{ trigger.json.event == 'opened' }}"
actions:
  - action: notify.notify
    data:
      title: "{{ trigger.json.issue.title }} ({{ trigger.json.issue.machine }})"
      message: "{{ trigger.json.issue.note or trigger.json.issue.id }}"

Try it

Under Home Assistant, press Send a test. It says at once whether it went, or why not.

  • Leave local_only on when Dokkit and Home Assistant share a network. Turn it off only when the request comes in through Home Assistant Cloud.
